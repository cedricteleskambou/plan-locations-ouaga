# Plan des locations à Ouagadougou

**Lien du site : https://cedricteleskambou.github.io/plan-locations-ouaga/**

## À quoi sert ce site

Ce site rassemble sur une seule page des annonces de location publiées sur Facebook à Ouagadougou. Tu vois les photos, le loyer et le quartier de chaque logement, puis tu contactes le propriétaire ou l'agent en un geste. Le site est pensé pour un téléphone, en particulier un iPhone.

## Quelles annonces sont gardées

Chaque annonce répond à l'un de ces deux cas :

| Type de logement | Loyer maximum par mois | Condition |
|---|---|---|
| Chambre-salon | 60 000 F CFA | Douche interne |
| 2 chambres-salon | 100 000 F CFA | Douche interne |

- **Douche interne** : la douche et les toilettes se trouvent à l'intérieur du logement.
- **Cuisine interne** : c'est un bonus. Les logements avec cuisine sont affichés en premier, et les autres restent dans la liste.
- **Date** : l'annonce a été publiée sur Facebook dans les 3 derniers jours.
- **Zone** : tout Ouagadougou.
- **Contact** : chaque annonce affiche au moins un numéro de téléphone.

## Comment utiliser la page

1. Ouvre le lien sur ton téléphone. Un mode d'emploi s'affiche à la première visite, et tu le retrouves ensuite avec le bouton « Mode d'emploi ».
2. Choisis le type de logement : chambre-salon, 2 chambres-salon ou les deux.
3. Trie la liste par cuisine, par date, par prix ou par quartier, ou choisis un quartier précis dans la liste déroulante.
4. Fais glisser les photos vers la gauche pour les voir toutes, et touche une photo pour l'agrandir.
5. Contacte la personne :
   - **Appeler** lance l'application Téléphone avec le numéro, et copie aussi le numéro au cas où l'appel ne démarre pas.
   - **WhatsApp** ouvre une conversation avec un message déjà écrit sur le logement.
   - **Voir sur Facebook** ouvre l'annonce d'origine, dans l'application Facebook si elle est installée.

## Mises à jour

La page vérifie toutes les 2 minutes si de nouvelles annonces ont été publiées. Quand c'est le cas, elle se recharge seule et garde tes choix (type, tri, quartier et position dans la liste).

## À retenir

Les annonces viennent de Facebook, donc vérifie toujours le logement sur place avant de verser de l'argent.
